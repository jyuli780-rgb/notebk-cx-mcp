# 使用教學：在 Codex 送出簡報需求

安裝完成並重開 Codex 後，就可以直接用白話對 Codex 下需求。若還沒安裝，請先看 [README](../README.md)。

---

## 一、先做一句話測試

```
請列出我 NotebookLM 裡的所有筆記本。
```

- 有列出筆記本，或清單為空但沒有報錯 → 串接成功。
- 出現認證錯誤 → 重新登入，見 [疑難排解](疑難排解.md)。

---

## 二、送出簡報需求

一次講清楚四件事：**主題、資料來源、受眾、重點**。並要求 Codex「送出前先讓你確認」，避免誤耗額度。

### 範本一：用網址當資料來源

```
請用 NotebookLM 幫我做一份簡報：
1. 建立新筆記本，名稱「（筆記本名稱）」。
2. 加入這個網址作為資料來源：（貼上網址）。
3. 語言用繁體中文，受眾是（受眾），重點放在（重點）。
4. 送出生成之前，先把設定唸給我確認。
```

### 範本二：用貼上的文字當資料來源

```
請用 NotebookLM 幫我做一份簡報：
1. 建立新筆記本，名稱「（筆記本名稱）」。
2. 把下面這段文字加入筆記本當資料來源：
（貼上文字）
3. 語言用繁體中文，受眾是（受眾），重點放在（重點）。
4. 送出生成之前，先把設定唸給我確認。
```

### 範本三：用既有的筆記本

```
請列出我的筆記本。我選「（筆記本名稱）」，
用裡面所有資料幫我生成簡報，繁體中文，
受眾是（受眾），重點放在（重點）。
送出之前，先把設定唸給我確認。
```

Codex 唸出設定後，回覆「確認，請送出」即可。

---

## 三、Codex 會依序做什麼

| 順序 | 工具 | 作用 |
|---|---|---|
| 1 | `notebook_create` | 建立筆記本 |
| 2 | `notebook_add_url` / `notebook_add_text` | 加入網址或文字資料 |
| 3 | `slide_deck_create` | 產生簡報（需你確認後才會真正送出） |
| 4 | `studio_status` | 查詢是否完成 |

---

## 四、可調整的參數

| 參數 | 選項 | 說明 |
|---|---|---|
| `format` | `detailed_deck`、`presenter_slides` | 詳細版適合自己閱讀；講者版適合上台 |
| `length` | `short`、`default` | 短版或標準長度 |
| `language` | `zh-TW`、`en`、`ja` … | 語言代碼。**預設是英文，要中文務必指定** |
| `focus_prompt` | 任意文字 | 想強調的重點、受眾與語氣 |

範例：

```
生成簡報時請用「講者版」（presenter_slides），長度用短版（short），語言 zh-TW。
```

---

## 五、取回簡報

簡報需要幾分鐘。請 Codex 查詢進度：

```
請查詢剛剛那份簡報的產生狀態，完成後告訴我。
```

**此 MCP 沒有提供簡報下載工具。** 完成後請打開 [notebooklm.google.com](https://notebooklm.google.com)，進入該筆記本的 **Studio** 區預覽與下載。

---

## 六、資料太少時：請 NotebookLM 先找資料

```
請在筆記本「（筆記本名稱）」開始研究主題「（主題）」，
研究完成後告訴我，我確認後再匯入來源。
```

---

## 七、讓簡報更好的三個習慣

1. 資料來源多給幾份，內容才不會空洞。
2. 在重點欄位寫清楚受眾與場合。
3. 先用短版試一次，滿意再出完整版。

---

## 八、使用前須知

- **非官方串接：** NotebookLM 改版時可能暫時失效，需等套件更新。
- **資料隱私：** 加入筆記本的資料會上傳到 Google，機密內容請先評估。
- **帳號安全：** 建議使用專用或次要的 Google 帳號。
- **額度有限：** 每日可產生的簡報次數有上限，用完隔天才恢復。
