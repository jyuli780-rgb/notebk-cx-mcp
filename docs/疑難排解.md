# 疑難排解

## 常見狀況

| 狀況 | 原因 | 處理 |
|---|---|---|
| 認證錯誤 | 登入憑證過期 | 重新登入，見下方「重新登入」 |
| 安裝時出現 `externally-managed-environment` | Homebrew 版 Python 的保護機制 | 改用 `uv tool install notebooklm-mcp-server`（需先安裝 uv）；使用一行安裝時，腳本會自動改用 uv |
| `which notebooklm-mcp` 沒有輸出 | 指令所在資料夾不在 PATH | 執行 `python3 -c "import sysconfig;print(sysconfig.get_path('scripts'))"`，印出的資料夾後面接 `/notebooklm-mcp` 就是完整路徑（Windows 見 [Windows 安裝說明](安裝說明-Windows.md)） |
| 登入時出現 `profile is already in use` | 上一次的授權視窗還開著 | 關掉那個視窗後重跑登入 |
| 登入視窗打不開 | Chrome 啟動失敗 | 先完全關閉所有 Chrome 再重跑；Windows 請確認 Chrome 安裝在 `C:\Program Files\Google\Chrome\Application\` |
| Codex 看不到 notebooklm 工具 | 沒有重開 Codex，或路徑錯誤 | 完全關閉並重開 Codex；用 `codex mcp list` 檢查 |
| 啟動逾時 | 第一次載入較慢 | 把 `config.toml` 裡的 `startup_timeout_sec` 調到 60 |
| 簡報遲遲沒好 | NotebookLM 還在產生 | 等 3 到 5 分鐘，再請 Codex 查詢進度 |
| 簡報變成英文 | 沒有指定語言 | 需求中註明繁體中文（`zh-TW`） |
| 簡報內容空洞 | 資料來源太少 | 多加資料來源，並寫清楚受眾與重點 |
| 一行安裝顯示「下載失敗」 | 網路問題 | 檢查網路後重試，或改用 `git clone` 後執行 `install.sh`（Windows：`install.cmd`） |

---

## 重新登入

登入憑證過期時，重跑登入指令即可：

```bash
notebooklm-mcp-auth
```

Windows 若提示找不到指令，請參考 [Windows 安裝說明](安裝說明-Windows.md) 找出完整路徑。

若自動登入一直失敗，還有手動匯入 Cookie 的備用模式，步驟較繁瑣，建議請講師協助：

```bash
notebooklm-mcp-auth --file
```

---

## 更新套件

```bash
python3 -m pip install -U notebooklm-mcp-server
```

使用 uv 安裝的人：

```bash
uv tool upgrade notebooklm-mcp-server
```

NotebookLM 改版造成失效時，先更新套件再試一次。

---

## 重新執行安裝腳本

安裝腳本可重複執行。已安裝、已註冊、已有逾時設定的項目會自動略過，不會重複設定。

---

## 解除安裝

依序執行下面三步（Windows 請在 PowerShell 執行）：

**1. 從 Codex 移除**

```bash
codex mcp remove notebooklm
```

**2. 移除套件**

```bash
python3 -m pip uninstall notebooklm-mcp-server
```

使用 uv 安裝的人：

```bash
uv tool uninstall notebooklm-mcp-server
```

**3. 刪除登入憑證與專用 Chrome 設定（選擇性）**

macOS / Linux：

```bash
rm -rf ~/.notebooklm-mcp
```

Windows（PowerShell）：

```powershell
Remove-Item -Recurse -Force $HOME\.notebooklm-mcp
```

安裝腳本修改 Codex 設定前留下的備份檔 `config.toml.bak-notebooklm`（在 `~/.codex/` 資料夾）可以一併刪除。

---

## 還是不行？

回報問題時請附上：

1. 你的系統（macOS / Windows / Linux）與版本
2. `codex --version` 與 Python 版本
3. 終端機顯示的完整錯誤訊息（**請先遮蔽任何帳號、路徑中的個人資訊**，且不要貼出 `auth.json` 的內容）
